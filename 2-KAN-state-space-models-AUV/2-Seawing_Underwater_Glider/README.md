------
These results were generated on 20/11/2025. 

This folder includes the simulation results in the file `NavigationSeawingDistubances_res_useful_data_only_v2.csv`. 
These results are generated by running the file `NavigationSeawingDistubances`, from OpenMAUVe (https://github.com/grande-dev/OpenMAUVe) at commit `dda5f03cc9fd293bac76adcd3f6ed2f1596461a6`.

The file runs a Seawing glider performing multiple yos. Heading reference changes every 3 yow, pitch reference changes from -25.0 deg (dive) to +25.0 deg (climb).
The VBD is actuated at full stroke both when climbing and when diving. The rolling mass controls the heading, the shifting mass controls the pitch. The latter two actuators are controlled via PIDs (tuned manually). 

The sensors used for the feedback have a white Gaussian noise (gain = 0.1, std = 0.1, sample period  = 1 s). 
The environmental disturbances are generated simulating the data of the South China Sea with gamma_1 = 0.01, gamma_2 = 100.0, gamma_3 = 130.0 noise_gain = 10.0;
All actuators include their own dynamics (tau_VBD = 2.5, tau_m_s = tau_m_r = 2.0). VBD is saturated at +-0.4, m_s is saturated at +-0.02, m_r is saturated at +-50.0. All saturation limited are constrained as output of the anti-wind up PID.

The scenario runs for 20000 seconds, at fixed time intervals of Dt = 0.1 s. 
The original resulting .csv file was ~13.3 GB, while this folder contains a sharable, lighter, version as `NavigationSeawingDistubances_res_useful_data_only_v2.csv`. 

## Analysis
The new file can be analysed with the Matlab script `s2_analyse_result_data.m`. The script simply extracts the variables for further analyses.  

## Dataset content  
The dataset convention and units are as follows:  

data.x1:  linear velocity along the x-axis [m/s]
data.x2: linear velocity along the y-axis [m/s]
data.x3: linear velocity along the z-axis [m/s]
data.x4: angular velocity around the x-axis [rad/s]
data.x5: angular velocity around the y-axis [rad/s]
data.x6: angular velocity around the z-axis [rad/s]

data.pos_x: inertial position along the x-axis [m] (ECI frame)
data.pos_y: inertial position along the y-axis [m] (ECI frame)
data.pos_z: inertial position along the z-axis [m] (ECI frame)

data.phi: roll attitude [rad] 
theta: pitch attitude [rad] 
psi: yaw attitude [rad] 
theta_deg: pitch attitude [deg] 
psi_deg: yaw attitude [deg] 

data.ref_theta: reference pitch attitude [deg] 
data.ref_psi: reference yaw attitude [deg] 

data.x_ECI_c: currents disturbance along the x-axis [m] (ECI frame)
data.y_ECI_c: currents disturbance along the y-axis [m] (ECI frame)
data.z_ECI_c: currents disturbance along the z-axis [m] (ECI frame)

data.u1: control signal of the VBD, including dynamics 
data.u2: control signal of the shifting mass, including dynamics 
data.u3: control signal of the rolling mass, including dynamics 

time: simulation time [s]
dt_vector: time step [s]
