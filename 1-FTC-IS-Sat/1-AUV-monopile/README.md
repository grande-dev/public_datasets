These results were originally generated on 11/12/2024. 

This folder includes the simulation results in the file `TestAUV_5d_CEGIS_LMI_monopile_res.csv`. 
These results are generated by running the file `Simulations/TestAUV_5d_CEGIS_LMI_monopile`, from OpenMAUVe v1.0.0 (https://github.com/grande-dev/OpenMAUVe) at commit `bcf21ebe7b8b23fbcf562a7b498dbdda4a394190`.  
The same scenario can be reproduced on OpenMAUVe v1.2.0 by running `Simulations/StateFeedbackControl_AH1_static_feedback` at commit `1e6ef86c846637334695bdd367d0d5d49a074f9a`.


This dataset file contains the results of an AUV moving in a planar motion around a monopile (i.e. the submerged part of an offshore wind turbine). The results are generated with the OpenMAUVe simulator. For a full description of the simulated scenario, refer to: "Fault-tolerant control of nonlinear systems: An inductive synthesis approach" (Masti, Grande, Peruffo, Fabiani).  

The simulation is set to last 5000s, but it will stop at 2295 s, when the AUV returns to the original position. The scenario is simulated at fixed time intervals of Dt = 0.1 s. 

## Analysis
The new file can be analysed with the Matlab script `analyse_dataset.m`. The script simply extracts the variables for further analyses.  

## Dataset content  
The dataset convention and units are as follows:  

data.generic_AUV_3d_out_lin_vel_u: linear velocity along the x-axis [m/s]
data.generic_AUV_3d_out_lin_vel_v: linear velocity along the y-axis [m/s]
data.generic_AUV_3d_out_lin_vel_w: linear velocity along the z-axis [m/s]

data.generic_AUV_3d_out_ang_vel_p: angular velocity around the x-axis [rad/s]
data.generic_AUV_3d_out_ang_vel_q: angular velocity around the y-axis [rad/s]
data.generic_AUV_3d_out_ang_vel_r: angular velocity around the z-axis [rad/s]

data.generic_AUV_3d_out_pos_x: inertial position along the x-axis [m]
data.generic_AUV_3d_out_pos_y: inertial position along the y-axis [m]
data.generic_AUV_3d_out_pos_z: inertial position along the z-axis [m]
data.generic_AUV_3d_out_angles_DCM_1_: roll attitude [rad]
data.generic_AUV_3d_out_angles_DCM_2_: pitch attitude [rad]
data.generic_AUV_3d_out_angles_DCM_3_: yaw attitude [rad]

data.generic_AUV_3d_F1: control input to thruster 1 [N]
data.generic_AUV_3d_F2: control input to thruster 2 [N]
data.generic_AUV_3d_F3: control input to thruster 3 [N]
data.generic_AUV_3d_F4: control input to thruster 4 [N]

% actuator efficiency -- just for extra check
data.faultInjection_4thrusters_h_1: thruster 1 actuator efficiency
data.faultInjection_4thrusters_h_2: thruster 2 actuator efficiency
data.faultInjection_4thrusters_h_3: thruster 3 actuator efficiency
data.faultInjection_4thrusters_h_4: thruster 4 actuator efficiency

time = data.time [s];
